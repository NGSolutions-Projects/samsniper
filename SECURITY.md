# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue, by email to
**security@samsniper.com**.

Include what you found, how to reproduce it, and the S.A.M. Sniper version
(About, in the app). We aim to acknowledge a report within 5 working days and
to tell you what we will do about it within 30.

Please do not test against SAM.gov, Grants.gov or any other service the
application talks to - report the problem in S.A.M. Sniper itself.

Other questions go to **support@samsniper.com**.
